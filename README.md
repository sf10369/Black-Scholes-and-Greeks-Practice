# Black-Scholes Option Pricing & Greeks

This project implements the Black-Scholes option pricing model in Python to value European call and put options. The project calculates all major option Greeks (Delta, Gamma, Theta, Vega, and Rho), verifies put-call parity, and analyzes option price sensitivity to changes in market parameters.

## Key Concepts Covered

- Black-Scholes Option Pricing
- European Call and Put Valuation
- Put-Call Parity Verification
- Delta, Gamma, Theta, Vega, and Rho
- Option Price Sensitivity Analysis
- Volatility Impact on Option Prices
- Risk Management Applications

## Technologies Used

- Python
- NumPy
- SciPy
- Pandas
- Matplotlib

## Project Highlights

- Implemented Black-Scholes pricing from scratch
- Computed all five major option Greeks
- Compared call and put sensitivities
- Visualized option price behavior across different stock prices
- Performed volatility sensitivity analysis
- Verified theoretical pricing relationships using put-call parity
